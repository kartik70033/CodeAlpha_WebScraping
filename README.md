CodeAlpha Data Analytics Internship

This repository contains my Data Analytics projects completed as part of the CodeAlpha Data Analytics Internship.

The projects demonstrate practical applications of Python for data collection, data analysis, visualization, and sentiment analysis.

About the Internship

The objective of this internship is to develop practical data analytics skills by working on different tasks involving data extraction, exploration, visualization, and interpretation.

Projects Completed

Task 1: Web Scraping

Notebook: "CodeAlpha_Data_Analytics.ipynb"

- Used Python Requests to access website content.
- Used BeautifulSoup to extract book information.
- Collected book titles, prices, ratings, and availability.
- Stored the extracted information in a Pandas DataFrame.
- Exported the collected data into a CSV file.

Dataset: "books_dataset.csv"

Task 2: Exploratory Data Analysis (EDA)

Notebook: "Task2codeAlpha_EDA.ipynb"

- Explored the structure and characteristics of the dataset.
- Checked missing values and statistical summaries.
- Analyzed book prices and ratings.
- Identified patterns and relationships between variables.
- Used charts and statistical analysis to understand the data.

Task 3: Data Visualization

Notebook: "CodeAlphaTask3_Data_Visualization.ipynb"

- Created visualizations using Matplotlib and Seaborn.
- Analyzed book price distributions.
- Visualized rating distributions.
- Compared average prices across ratings.
- Created charts to communicate findings effectively.

Task 4: Sentiment Analysis

Notebook: "CodeAlphaTask4_Sentiment_Analysis.ipynb"

- Performed sentiment analysis using TextBlob.
- Classified text into Positive, Negative, and Neutral categories.
- Calculated sentiment polarity scores.
- Visualized sentiment distribution.
- Interpreted the sentiment analysis results.

Note: This notebook currently uses sample review data for demonstrating sentiment analysis.

Installation and Setup

1. Clone this repository:
   
   "git clone https://github.com/kartik70033/CodeAlpha_WebScraping.git"

2. Navigate to the project directory:
   
   "cd CodeAlpha_WebScraping"

3. Install the required libraries:
   
   "pip install pandas numpy requests beautifulsoup4 matplotlib seaborn textblob jupyter"

4. Open Jupyter Notebook:
   
   "jupyter notebook"

5. Open the respective notebook and execute the cells.
